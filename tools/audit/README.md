# Audit tools (read-only; run from repo root with `.venv/bin/python`)
- `tools/audit/run_all.py [--last 8] [--save-baseline [PATH]] [--skip-perf]` → `context/metrics/latest.{md,json}` + guard deltas vs `baseline.json`.
- `tools/audit/eval_matches.py --checkpoint-dir DIR [--code-root PATH] [--matches 32] [--seed 1234] [--out JSON] [--keep-replays DIR]` → N fresh, unselected matches from a checkpoint (never writes checkpoints/replays) with per-match metrics and guard mean/se/n.
- `run_all.py --eval-checkpoint DIR [--eval-code-root PATH] [--eval-matches 32] [--save-baseline-unbiased]` → replay guards from fresh matches, compared with `baseline_unbiased.json`. Prefer this over `./replays` whenever training used `--save-best-only`.
- `tools/audit/harness.py --checkpoint-dir DIR --opp {self|scripted|scripted2|frozen:DIR} --mode {sampled|mixed|greedy} --n 96 --seed 11 --workers 10 --out-dir OUT [--sigma-scale S] [--swap] [--store-obs] [--breakdown]` → seeded full matches written as step-resolution `.npz` traces (checkpoint read-only; refuses to write inside any checkpoint dir or `checkpoints/`/`replays/`). Match `i` is identical for any `n`/`--workers`.
- `tools/audit/census.py TRACE_DIR [TRACE_DIR ...] [--json OUT]` → behaviour metrics over harness traces (possession, holder spells, kick outcomes, `n_within(R)`, clusters, role inversion, keeper opportunities, goal types) as mean +- SE with n. Metric definitions are in its module docstring. The scripted opponent is `football_rl/baselines.py`.
- `tools/audit/training_progress.py --bucket 100 --last-gens 15` → per-bucket interest/goals/passes/shots/tackles/saves/loose%/stationary.
- `tools/audit/replay_metrics.py --last 8` (or `--match ID`, `--gen G`, paths) → possession, width/depth, clustering, inversion, GK stats.
- `tools/audit/frame_inspect.py --match 13204 --frames 760 5531 [--viewer]` → full per-player state; `--viewer` = viewer frame counter.
- `tools/audit/retreat_probe.py --checkpoint-dir DIR [--seeds 11 12 13] [--rewards-override KEY=VALUE ...] [--json OUT]` → plays one match per seed, then reports the share of out-of-line covering defenders whose potential falls when they step 20 u back (overall / out of / in possession) and a cluster proxy from best-response ascent of out-of-possession outfielders. Overrides apply to the evaluation only, so before/after runs see the same states.
- `tools/audit/orphan_scan.py` → unread config fields, write-only attributes, unused aliases, duplicate-valued config fields.
- `tools/audit/perf_profile.py --steps 300 --seed 0 [--no-record]` → per-component ms/step and numpy calls/step.
- Every script takes `--json OUT` for full detail; stdout stays a short summary. Nothing writes to replays or source.
- Workflow: `run_all.py --save-baseline` before a change, `run_all.py` after it; read the delta column.
- Tests: `.venv/bin/python -m pytest tests/test_audit_tools.py -q`.
